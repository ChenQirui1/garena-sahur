# Message Schemas

Joint contract between the Minecraft, router and backend portions.

**Owners:** All five members — Elson, Daniel, Jerome, Richard, and Ivan.

No ownership group should change a schema on this page without informing the other two groups.

The agreed structures are currently recorded in
[Team Architecture and Ownership §8 — Shared Message Contracts](team-architecture.md#8-shared-message-contracts):
`world_snapshot`, `game_event`, `conversation_turn`, `routing_assignment`, and `behaviour_command`.

This file is the place to expand them into full field-level schemas — types, required
and optional fields, units, and validation rules — once the integrations firm up.
