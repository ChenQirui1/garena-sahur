# Demo Script

Final five-minute demonstration flow.

**Owners:** All five members — Elson, Daniel, Jerome, Richard, and Ivan.

This file is the place to write the run of show for the final demo: what happens on
screen, who drives each segment, and what the dashboard should be showing at each
moment.

The end-to-end path being demonstrated is Minecraft → router → LLM → Minecraft, as
described in [Team Architecture and Ownership §14 — Final Handoff Sequence](team-architecture.md#14-final-handoff-sequence).

The demo must be runnable in mock-model mode, so it survives an external model
provider being unavailable.
